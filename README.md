# PWA Household Accounting App

オフライン環境でも支出・収入を記録できる、PWA形式の家計簿アプリケーションです。

本システムは卒業論文

「PWA家計簿アプリケーションの設計と実装
― オフライン環境での継続利用を目的として ―」

の実装対象として開発します。

## 研究・開発の目的

既存の家計簿アプリケーションには、金融機関連携、AI分析、クラウド同期などの高度な機能を備えたものが多くあります。

一方、本システムでは、高度な機能を再現するのではなく、以下を重視します。

* 支出・収入を手軽に記録できること
* 通信環境がない場合でも主要機能を利用できること
* アカウント登録を必須としないこと
* 家計記録を端末内で扱えること
* 必要最低限の機能に絞り、操作を複雑にしないこと

## 完成目標

2026年7月中旬までに、専門学校で発表可能な状態まで完成させます。

完成時には、以下を満たすことを目標とします。

* 主要な家計簿機能が動作する
* 家計記録が端末内に保持される
* 初回読み込み後はオフラインでも利用できる
* スマートフォン及びパーソナルコンピュータで操作できる
* 動作確認及び評価結果を卒業論文へ記載できる

## 使用技術

現時点では、以下の構成を第一候補とします。

* HTML
* CSS
* JavaScript
* IndexedDB
* Service Worker
* Cache Storage
* Web App Manifest
* Storage API

JavaScriptについては、既存プロジェクトの状況を確認したうえで、フレームワークを使用せずに実装する構成を基本とします。

## 主要画面

本システムは、以下の4画面で構成します。

1. ホーム画面
2. 記録入力画面
3. 履歴画面
4. 集計画面

新規登録と編集では、同じ記録入力画面を使用します。

## 実装対象

### 家計記録

* 支出の登録
* 収入の登録
* 登録済み記録の編集
* 登録済み記録の削除
* 入力内容の検証

### 履歴

* 登録済み記録の一覧表示
* 記録日の新しい順での表示
* 同一記録日内での登録順表示

### 集計

* 今日の支出額
* 今月の支出額
* 月ごとの収入合計
* 月ごとの支出合計
* 月ごとの収支
* カテゴリ別支出
* 対象月の切替

### データ保存

* IndexedDBへの保存
* ページ再読み込み後の保持
* ブラウザまたはPWA再起動後の保持
* 登録・取得・更新・削除

### PWA・オフライン

* Web App Manifestの設定
* Service Workerの登録
* アプリケーションファイルのキャッシュ
* オフラインでの主要画面表示
* オフラインでの登録・閲覧・編集・削除
* オフラインでの集計
* 古いキャッシュの削除

## 実装対象外

2026年7月中旬までの実装では、以下を対象外とします。

* アカウント登録
* クラウド保存
* 複数端末間の同期
* レシート読取(OCR分析)
* AI分析
* 通知
* カテゴリの追加・編集
* 検索・絞り込み
* CSV・JSONによる入出力
* 削除済みデータの復元
* 高度なグラフ表示

## 開発方針

1. 最初にIndexedDBへの登録・取得を完成させる
2. 通常の家計簿機能を完成させる
3. PWA化とオフライン対応を行う
4. スマートフォン表示を調整する
5. 動作確認と評価を行う
6. 実装内容を卒業論文へ反映する

新しい機能を追加する前に、必須機能が正しく動作することを優先します。
