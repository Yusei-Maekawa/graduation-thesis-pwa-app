# 1. 研究題目
 
PWA家計簿アプリケーションの設計と実装
― オフライン環境での継続利用を目的として ―
 
# 2. 研究背景
・　家計記録は必要なときにすぐ入力できることが重要
・　既存アプリは高機能だが、登録・連携・画面情報量が負担になる場合がある
・　既存のアプリでは、クラウドや外部サービスに依存する機能が多い
・　家計簿記録では、通信できない状況でも基本的な記録を続けられる構成を検討する
 
# 3. 研究目的
・　必要最低限の家計記録機能を備える
・　初回読み込み後はオフラインで利用できる
・　家計記録を端末内で扱う
・　PWAによってWebアプリとインストール可能性を両立する
・　実装と動作評価を通して利点と課題を明らかにする
 
・4. 重要な設計方針
・　操作を複雑にしない
・　入力までの導線を短くする
・　画面上の情報量を増やしすぎない
・　スマートフォンを主な利用環境とする
・　オンライン・オフラインで操作を変えない
・　アカウント登録を必要としない
・　家計記録を外部へ送信しない
 
5. 研究範囲
 
実装対象：
 
登録
履歴
編集
削除
集計
IndexedDB
PWA
オフライン利用
画面適応
 
対象外：
 
認証
クラウド同期
金融機関連携
AI分析
レシート読取
カテゴリ管理
高度なグラフ
バックアップ
 
6. 評価方針
・　機能要件への適合
・　オフライン動作
・　再読み込み・再起動後の保持
・　画面幅への適応
・　外部送信を行わないこと
・　主観アンケートは現時点で行わない
 
7. AI利用上のルール
 
・　一工程ずつ実装する
・　後続機能を先取りしない
・　各処理を説明できるコードにする
・　未確定事項を勝手に決めない
・　実装と論文の不整合を報告する
・　ライブラリや抽象化を必要以上に増やさない
