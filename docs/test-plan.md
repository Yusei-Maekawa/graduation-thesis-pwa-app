# テスト計画

## 1. 本書の目的

本書では、PWA家計簿アプリケーションが、仕様書及び卒業論文第3章で定めた要件を満たしているかを確認するためのテスト項目を定める。

本書は、次の2つを目的とする。

1. 2026年7月中旬版の完成判定に使用する
2. 卒業論文第6章「評価・考察」における評価項目及び評価結果の基礎資料とする

テスト実施時には、各項目について実際の結果を記録し、期待結果を満たした場合を合格とする。

---

## 2. 評価方針

本研究では、利用者の主観的な満足度を直接評価するのではなく、次の観点を中心に確認する。

- 設定した機能要件を実現できていること
- 通信がない状態でも主要機能を利用できること
- 家計記録が再読み込み及び再起動後にも保持されること
- スマートフォン及びパーソナルコンピュータで主要操作を行えること
- 家計記録を外部サービスへ送信せず、端末内で扱えること
- 入力内容の不備や操作結果を利用者が確認できること

本研究では、長期間の継続利用調査及び利用者アンケートを必須の評価対象としない。

将来、利用者の主観的な使いやすさを評価する場合には、独自の質問項目を作成するのではなく、SUSなど既存の評価方法の利用を検討する。

---

## 3. テスト対象

### 3.1 対象機能

- 支出・収入の新規登録
- 登録済み記録の編集
- 登録済み記録の削除
- 履歴表示
- 今日及び今月の支出表示
- 月別の収入・支出・収支表示
- カテゴリ別支出表示
- 対象月の切替
- IndexedDBへの保存
- PWAとしての起動
- オフラインでの画面表示及び家計記録操作
- スマートフォン及びパーソナルコンピュータへの画面適応



### 3.2 対象外

- アカウント登録
- クラウド保存
- 複数端末間の同期
- 金融機関連携
- レシート読取
- 通知
- カテゴリ管理
- データのバックアップ・復元
- 長期間の継続利用
- 大規模な負荷試験
- すべての端末及びブラウザでの動作保証

# 14. 完成判定



## 14.1 必須合格項目

2026年7月中旬版は、次の項目をすべて満たした場合に完成とする。

- 支出・収入を登録できる
- 入力不備を保存せず、修正箇所を確認できる
- 登録済み記録を履歴で確認できる
- 記録を編集できる
- 記録を削除できる
- 今日及び今月の支出額が正しく表示される
- 月別の収入、支出及び収支が正しく表示される
- カテゴリ別支出が正しく表示される
- 再読み込み後も記録が保持される
- ブラウザ又はPWA再起動後も記録が保持される
- 初回読み込み後、オフラインで主要4画面を表示できる
- オフラインで登録・閲覧・編集・削除・集計ができる
- スマートフォンで主要操作を行える
- PWAとして起動できる
- 発表用のデモを実施できる



## 14.2 判定区分


| 判定     | 内容                        |
| ------ | ------------------------- |
| 合格     | 期待結果を満たした                 |
| 条件付き合格 | 主要動作は可能だが、軽微な表示上の問題などがある  |
| 不合格    | 期待結果を満たさず、主要機能又は研究目的に影響する |
| 未実施    | テストを実施していない               |
| 対象外    | 最終仕様で実装対象外となった            |




## 14.3 不具合の優先度


| 優先度      | 内容                           |
| -------- | ---------------------------- |
| Critical | データ消失、アプリ起動不可、主要機能を利用できない    |
| High     | 登録・編集・削除・集計・オフライン動作に重大な誤りがある |
| Medium   | 一部条件で操作又は表示に問題がある            |
| Low      | 文言、余白、軽微な表示崩れなど、主要動作に影響しない   |


Critical及びHighの不具合が残っている場合は、7月中旬版を完成とは判定しない。
